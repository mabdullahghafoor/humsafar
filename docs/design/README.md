# design/ — Screen designs

**Owner:** Sarim

The working design lives in Figma (file: *Humsafar – App Design*). This folder holds exported snapshots (PNG/PDF) for each task, so the repo has a record of what each screen was built from.

**Planned contents**
- `0.7_wireframes/` — low-fidelity wireframes for every SDS 10.1 screen
- `1.12_identity_access/` — registration, login, KYC, permissions mockups
- `2.8_map_geofence/` — Live Map, geofence config, Dependent Mode home
- `3.9_dependent_mode/` — Dependent Mode + Guardian alert/config screens

**File naming:** `Humsafar_Design_<Screen>_v<version>.png`, e.g. `Humsafar_Design_Login_v1.0.png`

**Figma file:** https://www.figma.com/design/fpY8fd72McW3iVS0PydHtw/Humsafar-App-Design (view access: Abdullah, Talha)
