# design/archive/ — Earlier versions of the screens (design history)

**Owner:** Sarim

This folder keeps every earlier version of the hi-fi screens, so the design process is visible step by step: the first interfaces (v0.1), the contrast fix of the style guide (v0.2, NFR-08), screens matched to the API contracts as the backend was built, and the colour update of 30 Oct 2026. **Do not build from these files**: the current versions are in the main folders (`../<folder>/`). The low-fidelity wireframes stay in `../0.7_wireframes/` (marked superseded).

The subfolders mirror the main design folders. File names are unchanged (`Humsafar_Design_<number>_<Screen>_v<version>.png`), so the version number shows the order. 82 files.

## How the versions moved
1. **v0.1 (Sept–Oct 2026):** first hi-fi interfaces from the wireframes (0.7), one set per phase (1.12, 2.8, 3.9, 4.9, 5.9, 6.11, coverage).
2. **Style guide v0.2 (21 Oct):** danger red `#DC2626` → `#B91C1C` and muted grey `#64748B` → `#475569` so all text meets WCAG AA (NFR-08, `docs/qa/Humsafar_QA_NFR-08_Contrast_Check_v1.0.pdf`).
3. **Contract versions (20–22 Oct):** screens updated to match the backend API contracts as each task was built (records, vitals, band, directory, booking, camera, analytics, account, audit).
4. **Colour update (30 Oct):** the 47 screens still drawn with the old two colours moved to the v0.2 colours, colours only.
