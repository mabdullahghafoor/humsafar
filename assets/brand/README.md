# assets/brand/ — Humsafar brand

**Owner:** Sarim · Logo design: team logo designer · Status: **logo in progress** (folders ready)

| Folder | What goes here |
|---|---|
| `brief/` | `Humsafar_Logo_Brief_v1.0.pdf` (what the app is, logo direction, colours, rules, slogan options) and `Humsafar_Gemini_Logo_Prompts_v1.0.md` (copy-paste prompts) |
| `concepts/` | Selected concept images from Gemini or the designer (for the record only) |
| `logo/source/` | Master files from the designer: `.ai`, `.fig` or master `.svg` |
| `logo/exports/` | Final exports: SVG + PNG at 1024 / 512 / 192 / 48 px, each version (colour, one-colour, white-on-teal, black; icon, horizontal, stacked, bilingual) |
| `app-icon/` | Android adaptive icon: foreground + background layers, 1024 × 1024. Talha generates the launcher icons from these |

**File naming:** `Humsafar_Logo_<version>_<variant>_<size>.<ext>`, e.g. `Humsafar_Logo_v1.0_horizontal_colour_1024.png`.

**Brand basics (until the final logo is in):** main colour teal-blue `#0E7490`, dark `#155E75`, light `#ECFEFF`; no red in the logo (red = Panic in the app). Slogan: to be chosen from the brief (recommended: "Care that travels with you." / "ہر قدم، ساتھ ساتھ").
